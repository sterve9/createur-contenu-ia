C-V2-03 · Lire Contexte V1
Type de nœud : Postgres — Execute Query

🔧 Corrigé le 06/08/2026 (ADR-V2-03) — Chemin FK aligné sur la réalité Supabase.
Ancienne requête utilisait s.campagne_id (colonne inexistante) et
a.contenu_id = s.contenu_id. Nouvelle requête : s.analyse_id → a.id → c.id → camp.id.

Requête :

SQL

SELECT
  s.id            AS script_id,
  s.script        AS script_texte,
  a.id            AS analyse_id,
  a.theme         AS theme,
  a.mots_cles     AS mots_cles,
  a.sentiment     AS sentiment,
  a.score_qualite AS score_qualite,
  a.resume        AS resume,
  c.id            AS contenu_id,
  c.titre         AS titre_contenu,
  c.auteur        AS auteur_contenu,
  c.plateforme    AS plateforme_contenu,
  c.campagne_id   AS campagne_id,
  camp.statut     AS statut_campagne_v1
FROM public.scripts s
JOIN public.analyses  a    ON a.id    = s.analyse_id
JOIN public.contenus  c    ON c.id    = a.contenu_id
JOIN public.campagnes camp ON camp.id = c.campagne_id
WHERE s.id = {{ $json.body.script_id }}
  AND camp.statut = 'TERMINEE'
LIMIT 1;
⚠️ Le filtre camp.statut = 'TERMINEE' joue le rôle
de validation métier : si la requête retourne 0 ligne,
le script n'existe pas ou la campagne V1 n'est pas terminée.
Le workflow s'arrête sans écriture.

C-V2-07 · Normaliser Scènes
Type de nœud : Code (JavaScript)

JavaScript

const dossier_id = $('Créer Dossier V2').first().json.dossier_id;
const results = [];

for (const item of $input.all()) {
  let raw = '';
  if (Array.isArray(item.json.content)) {
    const textBlock = item.json.content.find(b => b.type === 'text');
    if (textBlock) raw = textBlock.text.trim();
  }
  if (raw.startsWith('```')) {
    raw = raw.replace(/^```[a-z]*\n?/i, '').replace(/```\s*$/, '').trim();
  }
  let parsed;
  try {
    parsed = JSON.parse(raw);
  } catch (e) {
    throw new Error('Échec du parsing JSON scènes : ' + raw.substring(0, 200));
  }
  if (!parsed.scenes || !Array.isArray(parsed.scenes)) {
    throw new Error('Structure JSON invalide : tableau scenes absent');
  }
  for (const scene of parsed.scenes) {
    if (!scene.numero_scene || !scene.texte_narratif
        || !scene.ambiance_visuelle || !scene.duree_estimee) {
      throw new Error('Scène incomplète — champs obligatoires manquants : ' + JSON.stringify(scene));
    }
    results.push({
      json: {
        dossier_id,
        numero_scene      : scene.numero_scene,
        texte_narratif    : scene.texte_narratif,
        ambiance_visuelle : scene.ambiance_visuelle,
        duree_estimee     : scene.duree_estimee
      }
    });
  }
}
return results;
C-V2-08 · Persister Scènes
Type de nœud : Postgres — Execute Query (boucle sur chaque scène)

Requête :

SQL

INSERT INTO v2_scenes (
  dossier_id,
  numero_scene,
  texte_narratif,
  ambiance_visuelle,
  duree_estimee
)
VALUES (
  {{ $json.dossier_id }},
  {{ $json.numero_scene }},
  '{{ $json.texte_narratif }}',
  '{{ $json.ambiance_visuelle }}',
  {{ $json.duree_estimee }}
)
ON CONFLICT (dossier_id, numero_scene) DO UPDATE
  SET texte_narratif    = EXCLUDED.texte_narratif,
      ambiance_visuelle = EXCLUDED.ambiance_visuelle,
      duree_estimee     = EXCLUDED.duree_estimee
RETURNING id AS scene_id, dossier_id, numero_scene,
          texte_narratif, ambiance_visuelle, duree_estimee;
L'ON CONFLICT garantit l'idempotence.

JavaScript

const dossier_id = $('Créer Dossier V2').first().json.dossier_id;
const results    = [];
let raw = '';

  const textBlock = $json.content.find(b => b.type === 'text');

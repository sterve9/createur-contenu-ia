# 00 - Contexte du Client

## Rôle du document
Ce document est le point d'entrée de toute mission d'architecture.
Il permet de comprendre le client avant d'analyser son problème.
Il répond aux questions suivantes :

* Qui est le client ?
* Quelle est son activité ?
* Qui sont ses clients ?
* Comment crée-t-il de la valeur ?
* Comment travaille-t-il aujourd'hui ?
* Quels outils utilise-t-il ?
* Quelles sont ses principales difficultés ?
* Quelles tâches relèvent de son expertise ?
* Quelles tâches pourraient être automatisées ?
* Quels sont ses objectifs ?
* Quels sont les critères de réussite du projet ?

Ce document ne décrit jamais :
* la solution technique ;
* les workflows ;
* les composants ;
* la base de données ;
* les outils d'automatisation.

---

## 1. Présentation du client
* **Nom du métier :** Créateur de contenu IA
* **Description de l'activité :** Le créateur produit des contenus (vidéos, images, textes ou publications) à destination des réseaux sociaux en utilisant des outils d'intelligence artificielle. Son objectif est de développer une audience, générer des revenus (publicité, formations, prestations ou affiliations) et renforcer sa visibilité en ligne.

## 2. Les clients du client
Le créateur de contenu s'adresse principalement à :
* des entrepreneurs ;
* des freelances ;
* des créateurs débutants ;
* des passionnés d'IA ;
* des entreprises souhaitant découvrir ou utiliser les outils d'IA.

## 3. Proposition de valeur
Le créateur aide son audience à gagner du temps, découvrir de nouveaux outils et apprendre à utiliser l'intelligence artificielle grâce à des contenus simples, pratiques et pédagogiques.

## 4. Fonctionnement actuel
Aujourd'hui, le processus de création est principalement manuel.
Pour chaque contenu, il doit :
* rechercher une idée ;
* écrire un scénario ;
* créer les personnages ou les visuels ;
* générer les images ;
* produire les vidéos ;
* monter les séquences ;
* ajouter les sous-titres ;
* publier sur les différentes plateformes.

Chaque vidéo demande de nombreuses manipulations répétitives entre plusieurs outils.

## 5. Outils utilisés
Exemple d'outils actuellement utilisés :
* ChatGPT (idées, scripts, prompts) ;
* Google Flow (génération vidéo) ;
* CapCut (montage vidéo) ;
* TikTok ;
* YouTube ;
* Instagram.

*Cette liste pourra évoluer avec le temps.*

## 6. Difficultés rencontrées
Les principales difficultés sont :
* le temps nécessaire pour produire chaque vidéo ;
* la répétition des mêmes opérations ;
* la gestion de plusieurs outils différents ;
* le risque d'oublier certaines étapes ;
* la difficulté à maintenir un rythme de publication élevé.

## 7. Expertise métier
Les tâches qui relèvent de l'expertise du créateur sont :
* choisir les sujets ;
* raconter une histoire captivante ;
* transmettre ses connaissances ;
* comprendre son audience ;
* construire sa stratégie de contenu.

*Ces tâches ne doivent pas être remplacées par l'automatisation.*

## 8. Tâches potentiellement automatisables
Les tâches candidates à l'automatisation sont notamment :
* génération des prompts ;
* génération des scripts ;
* préparation des images ;
* génération des vidéos ;
* organisation des fichiers ;
* publication multi-plateforme ;
* suivi des performances.

## 9. Objectifs du projet
Le système devra permettre de :
* produire davantage de contenus en moins de temps ;
* standardiser le processus de production ;
* réduire les tâches répétitives ;
* conserver une qualité constante ;
* laisser davantage de temps à la création et à la stratégie.

## 10. Critères de réussite
Le projet sera considéré comme réussi si :
* le temps de production d'une vidéo est significativement réduit ;
* le processus est reproductible ;
* les étapes sont clairement définies ;
* les tâches répétitives sont automatisées ;
* le créateur peut se concentrer sur les décisions créatives.

## 1. Objectif du document

Ce document définit le catalogue officiel des outils image et
animation disponibles en V2.

Pour chaque outil, il documente :
- les informations générales (catégorie, tier, accès) ;
- les conventions de prompt spécifiques à l'outil ;
- les contraintes techniques à respecter.

Les conventions de prompt documentées ici sont injectées
directement dans les prompts des générateurs IA V2
(composants C-V2-13 et C-V2-16).

Ce document est conçu pour évoluer indépendamment du reste
de la documentation V2. L'ajout d'un nouvel outil ne nécessite
aucune modification des autres documents.

---

## 2. Structure d'une fiche outil

Chaque outil est documenté selon la structure suivante :

| Champ | Description |
|---|---|
| `outil_id` | Identifiant technique utilisé dans `v2_catalogue_outils` |
| `nom` | Nom affiché au créateur |
| `categorie` | `IMAGE` ou `ANIMATION` |
| `tier` | `GRATUIT`, `FREEMIUM` ou `PAYANT` |
| `acces` | URL d'accès à l'outil |
| `description` | Présentation courte de l'outil |
| `conventions_prompt` | Règles et vocabulaire à respecter pour ce prompt |
| `contraintes` | Limites techniques (longueur, format, etc.) |
| `exemple_prompt` | Exemple de prompt bien formé pour cet outil |

### 3.1 Playground AI

| Champ | Valeur |
|---|---|
| `outil_id` | `playground-ai` |
| `nom` | Playground AI |
| `categorie` | IMAGE |
| `tier` | FREEMIUM |
| `acces` | https://playground.com |
| `description` | Plateforme web de génération d'images IA. Interface accessible, orientée marketing et réseaux sociaux. Idéal pour les créateurs sans expérience en prompt engineering. Génération gratuite limitée par jour. |

**Conventions de prompt** :
- Rédiger en anglais pour de meilleurs résultats.
- Décrire le sujet principal en premier, puis l'environnement,
  puis l'ambiance et l'éclairage.
- Utiliser des qualificatifs visuels précis :
  `cinematic lighting`, `sharp focus`, `high detail`,
  `professional photography`.
- Préciser le ratio souhaité : `16:9` pour YouTube,
  `9:16` pour TikTok / Reels.
- Éviter les phrases complètes : préférer les groupes
  nominaux séparés par des virgules.

**Contraintes** :
- Longueur maximale recommandée : 300 caractères.
- Ne pas inclure de noms propres de personnalités réelles.
- Génération gratuite : environ 50 images par jour.

**Exemple de prompt** :
Young entrepreneur at a modern desk, laptop open, city view
background, warm golden hour light, cinematic lighting,
sharp focus, 9:16 vertical format, professional photography

### 3.4 Midjourney

| Champ | Valeur |
|---|---|
| `outil_id` | `midjourney` |
| `nom` | Midjourney |
| `categorie` | IMAGE |
| `tier` | PAYANT |
| `acces` | https://www.midjourney.com |
| `description` | Référence du marché en génération d'images IA. Qualité visuelle supérieure, style artistique distinctif. Abonnement mensuel requis. Utilisé via interface web ou Discord. Idéal pour un contenu à forte identité visuelle. |

**Conventions de prompt** :
- Rédiger en anglais.
- Structure recommandée :
  `[sujet principal] + [contexte/environnement] +
  [style artistique] + [paramètres techniques]`.
- Paramètres importants à ajouter en fin de prompt :
  `--ar 9:16` (ratio), `--v 6` (version),
  `--style raw` (moins de post-traitement),
  `--q 2` (qualité maximale).
- Qualificatifs de style efficaces :
  `cinematic`, `editorial`, `hyper-realistic`,
  `shot on Sony A7`, `natural light`.
- Éviter les constructions trop complexes :
  Midjourney interprète mieux les prompts concis et précis.

**Contraintes** :
- Abonnement requis à partir de 10 $/mois.
- Longueur maximale : 60 mots environ pour les meilleurs résultats.
- Générations soumises aux conditions d'utilisation Midjourney.

**Exemple de prompt** :
young entrepreneur filming content in a bright minimalist studio,
confident posture, ring light, clean white background,
editorial photography style, cinematic, natural light
--ar 9:16 --v 6 --style raw

### 4.1 Kling AI

| Champ | Valeur |
|---|---|
| `outil_id` | `kling-ai` |
| `nom` | Kling AI |
| `categorie` | ANIMATION |
| `tier` | FREEMIUM |
| `acces` | https://klingai.com |
| `description` | Outil de génération vidéo IA (image vers vidéo, texte vers vidéo). Résultats réalistes, mouvement fluide. Crédits gratuits quotidiens disponibles. Très utilisé par les créateurs de contenu court. |

**Conventions de prompt** :
- Rédiger en anglais.
- Décrire le mouvement principal en premier :
  `slow zoom in`, `camera pan left`, `subject walks forward`.
- Préciser la durée souhaitée :
  `5 second clip`, `short loop`.
- Décrire l'ambiance du mouvement :
  `smooth`, `dynamic`, `cinematic`, `gentle`.
- En mode image-vers-vidéo : le prompt décrit uniquement
  le mouvement, pas le contenu de l'image (déjà fournie).

**Contraintes** :
- Durée maximale par génération : 5 à 10 secondes selon le mode.
- Crédits gratuits limités quotidiennement.
- Format de sortie : MP4.

**Exemple de prompt** :
slow cinematic zoom in, subject stays still, soft background
blur increases, warm lighting, smooth motion, 5 second clip

## 5. Règles de gouvernance du catalogue

| Règle | Description |
|---|---|
| R-CAT-01 | Tout outil ajouté au catalogue doit comporter les 9 champs de la structure standard. |
| R-CAT-02 | Les `outil_id` sont des identifiants techniques stables. Une fois définis, ils ne changent pas, même si le nom de l'outil évolue. |
| R-CAT-03 | Les conventions de prompt sont rédigées sans syntaxe de workflow. Elles sont injectées telles quelles dans le prompt du générateur IA. |
| R-CAT-04 | L'ajout d'un outil ne nécessite aucune modification des documents V2-008 ou V2-009. |
| R-CAT-05 | Un outil retiré du catalogue est marqué `statut = INACTIF` dans `v2_catalogue_outils`. Il n'est pas supprimé, pour préserver la traçabilité des campagnes existantes. |
| R-CAT-06 | La liste des outils V3 (stack open source / locale) est documentée dans le backlog V3, hors périmètre de ce catalogue. |
